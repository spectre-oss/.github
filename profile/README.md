<h1 align="center">Spectre OSS</h1>

<p align="center">Understand the hardware. Build open software.</p>

Spectre OSS is a home for open-source hardware reverse engineering, Linux device support, and system software. We investigate how devices work, document what we learn, and build software that gives their hardware new possibilities.

Our work spans hardware research, kernel and driver development, operating-system integration, and native user interfaces. We aim to publish reproducible builds, clear technical evidence, and honest accounts of what works and what remains experimental.

## First project: Rabbit R1

**[Spectre for Rabbit R1](https://github.com/spectre-oss/rabbit-r1)** is an independent effort to build a Linux software stack for the Rabbit R1, from device support to the user interface.

| Repository | Focus |
| --- | --- |
| [rabbit-r1](https://github.com/spectre-oss/rabbit-r1) | Project overview, documentation, and future integration. |
| [rabbit-r1-kernel](https://github.com/spectre-oss/rabbit-r1-kernel) | Linux kernel changes and device support. |
| [rabbit-r1-os](https://github.com/spectre-oss/rabbit-r1-os) | Spectre OS, image tooling, and device services. |
| [spectre-launcher](https://github.com/spectre-oss/spectre-launcher) | Native launcher and device user interface. |

**Public source releases are in preparation.** The component repositories are being established; there is no public installable OS release yet. Follow the [project overview](https://github.com/spectre-oss/rabbit-r1) for release readiness and next steps.

## How we work

- **Evidence first.** Distinguish measured behavior from assumptions and pending validation.
- **Reproducible results.** Publish build instructions, dependencies, and known limitations alongside source.
- **Respect for upstream work.** Preserve attribution and component licenses, and document the origin of imported code.
- **Knowledge worth sharing.** Turn device-specific findings into useful documentation and reusable tools where possible.

## Get involved

Hardware findings, driver contributions, reproducible bug reports, and documentation improvements are welcome. Start with the relevant project's README and issues. While the initial source releases are being prepared, use [Rabbit R1 issues](https://github.com/spectre-oss/rabbit-r1/issues) for focused questions and research findings.

Please remove credentials, personal information, and device-specific identifiers from logs before sharing them.
